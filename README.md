# video_portal_client

Frontend client for **Video Portal**, built with **Next.js**, **React**, and **TypeScript**. It
provides a modern user interface for browsing, uploading, and managing videos, and communicates with
the [video_portal_server](https://github.com/Timson4eg/video_portal_server) backend.

---

## 🚀 Installation

```bash
git clone https://github.com/Timson4eg/video_portal_client.git
cd video_portal_client
npm install
# or
yarn install
# or
bun install
```
